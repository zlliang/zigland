# ⚡️ Zigland

> Grow together with [Zig](https://ziglang.org).

**[zigland.dev](https://zigland.dev)** — Your hub for learning and exploring the Zig programming language, and more broadly, system programming.

🚧 **Status:** Work in Progress

## About

Zigland is your hub for learning and exploring the Zig programming language and system programming. The vision is to provide:

- **Comprehensive Tutorials** — Learn Zig and system programming from the ground up
- **Interactive Playground** — Experiment with Zig code in your browser (inspired by [typescriptlang.org/play](https://typescriptlang.org/play))
- **Language Cheat Sheet** — Quick reference guide (inspired by [cheats.rs](https://cheats.rs))
- **Newsletters and Posts** — Regular updates about Zig and its ecosystem
